# Contributing

Use Node 22–24 and npm. Run `npm ci`, `npm run verify` and `npm run test:e2e`.
For the browser suite, first run `npx playwright install chromium`.

Keep lesson explanations next to dated, direct sources. Add a regression test
when changing playback timing. Distinguish browser target, recorded demonstration
and measured hardware feedback. Do not add imagined sensor readings or claims
of hardware accuracy. Keep all examples independent of accounts and robots.

Small useful contributions include clearer joint explanations, keyboard access,
mobile layout improvements and source corrections. Describe the observed problem,
the intended change and how to reproduce it. Never include private conversations,
personal data, keys, local home paths or generated review artifacts.
